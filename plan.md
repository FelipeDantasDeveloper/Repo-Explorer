# Repo Explorer 1.0

## Sobre o projeto

O Repo Explorer é uma aplicação web desenvolvida com o objetivo de pesquisar e visualizar repositórios públicos do GitHub de maneira simples e organizada.

O projeto foi criado para colocar em prática meus conhecimentos em JavaScript, especialmente consumo de APIs, manipulação do DOM, programação assíncrona e tratamento de erros.

## Funcionalidades

- Pesquisa de repositórios utilizando a API pública do GitHub.
- Exibição dinâmica dos resultados.
- Visualização do nome, descrição, imagem do proprietário e quantidade de estrelas dos repositórios.
- Acesso direto aos repositórios encontrados.
- Validação de campos vazios.
- Tratamento de erros e pesquisas sem resultados.
- Indicador de carregamento durante as requisições.
- Interface responsiva para diferentes tamanhos de tela.

## Tecnologias utilizadas

- **HTML5:** estrutura da aplicação.
- **CSS3:** estilização e responsividade.
- **JavaScript:** lógica, eventos e manipulação do DOM.
- **GitHub REST API:** consulta aos repositórios públicos.

## Aprendizados

Durante o desenvolvimento, pratiquei a utilização de `fetch()`, `async/await`, estruturas condicionais, manipulação de elementos HTML e tratamento de respostas HTTP.

Também trabalhei na resolução de problemas relacionados ao layout, validação de dados e experiência do usuário.

## Objetivo

Consolidar meus conhecimentos em desenvolvimento Front-End por meio da construção de uma aplicação funcional, utilizando recursos e problemas encontrados no desenvolvimento web.
